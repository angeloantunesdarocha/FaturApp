\# Prompt Command — Create Project



\## Comando



/create-project



\---



\## Função



Criar um projeto completo seguindo padrões profissionais de engenharia de software.



\---



\# Processo Obrigatório



Ao receber uma solicitação de novo projeto:



\## 1. Análise Inicial



Identificar:



\- objetivo do sistema;

\- problema resolvido;

\- usuários;

\- funcionalidades principais;

\- regras de negócio.



Se informações importantes estiverem faltando, solicitar esclarecimentos.



\---



\## 2. Planejamento



Criar:



\- visão geral do projeto;

\- requisitos funcionais;

\- requisitos técnicos;

\- riscos identificados.



\---



\## 3. Arquitetura



Definir:



\- frontend;

\- backend;

\- banco de dados;

\- APIs;

\- autenticação;

\- integrações.



Seguir:



\- architecture-rules.md;

\- stack.md.



\---



\## 4. Banco de Dados



Aplicar:



\- database-design.md.



Definir:



\- tabelas;

\- relacionamentos;

\- permissões;

\- segurança.



\---



\## 5. Desenvolvimento



Executar seguindo:



\- coding-standards.md;

\- workflow.md;

\- security-rules.md.



Criar:



\- estrutura do projeto;

\- componentes;

\- APIs;

\- funcionalidades.



\---



\## 6. Testes



Validar:



\- funcionamento;

\- segurança;

\- erros;

\- experiência do usuário.



\---



\## 7. Entrega



Preparar:



\- documentação;

\- instruções de execução;

\- deploy.



Usar:



\- deploy-production.md.



\---



\# Memória



Registrar em:



.ai/memory/



\- decisões técnicas;

\- arquitetura escolhida;

\- tecnologias utilizadas;

\- aprendizados importantes.



\---



\# Resultado Esperado



Nunca entregar apenas código.



Entregar uma solução completa de software.
