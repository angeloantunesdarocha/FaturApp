\# Technology Stack Knowledge



\## Objetivo



Este documento define as tecnologias principais utilizadas pelo agente.



O agente deve considerar esta stack como referência inicial para projetos modernos.



\---



\# Frontend



\## React



Utilizar para criação de interfaces modernas baseadas em componentes.



Boas práticas:



\- componentes reutilizáveis;

\- estado bem organizado;

\- separação de responsabilidades;

\- hooks utilizados corretamente.



\---



\## Next.js



Framework principal para aplicações web completas.



Utilizar recursos como:



\- App Router;

\- Server Components;

\- Server Actions;

\- otimização de performance;

\- rotas organizadas.



Considerar:



\- SEO;

\- carregamento rápido;

\- experiência do usuário.



\---



\## TypeScript



Linguagem padrão.



Sempre preferir:



\- tipos explícitos;

\- interfaces;

\- segurança durante desenvolvimento;

\- código previsível.



Evitar:



\- uso excessivo de any;

\- tipagem fraca.



\---



\## Tailwind CSS



Utilizar para:



\- criação rápida de interfaces;

\- padronização visual;

\- responsividade.



Manter:



\- classes organizadas;

\- componentes reutilizáveis.



\---



\# Backend



\## Node.js



Utilizar para:



\- APIs;

\- processamento;

\- integrações;

\- automações.



Seguir:



\- tratamento correto de erros;

\- organização por módulos.



\---



\# Banco de Dados



\## PostgreSQL



Banco relacional principal.



Considerar:



\- modelagem correta;

\- relacionamentos;

\- índices;

\- segurança.



\---



\## Supabase



Utilizar quando necessário:



\- autenticação;

\- banco PostgreSQL;

\- armazenamento;

\- APIs;

\- funções serverless.



Aplicar:



\- Row Level Security;

\- controle de permissões;

\- boas práticas de segurança.



\---



\# Versionamento



\## Git



Todo projeto profissional deve utilizar:



\- commits organizados;

\- branches quando necessário;

\- histórico limpo.



\---



\## GitHub



Utilizar para:



\- armazenamento de código;

\- colaboração;

\- documentação;

\- controle de versões.



\---



\# Deploy



\## Vercel



Preferencialmente para:



\- aplicações Next.js;

\- projetos frontend;

\- APIs integradas.



Considerar:



\- variáveis de ambiente;

\- logs;

\- monitoramento.



\---



\# Regra Técnica



Escolher tecnologias pela necessidade do projeto.



Não adicionar ferramentas sem motivo.



Simplicidade e manutenção são prioridades.
